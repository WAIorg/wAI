### Official Repository of Wai

## Folders Structure
# Each folder contains their own README and requirements files
- backend: Server for running kinect driver software, streaming and saving RBG/depth images, and performing the calibration transformations
    - CODER OWNER: ALEXIS 
- frontend: Running the UI for the datacollection interface
    - CODER OWNER: ALEXIS 
- depth-image: artificially creating depth image with only rgb
    - CODER OWNER: ALEXIS 
- image-degmentation: 2D image segemtation
    - CODER OWNER: MACKENZIE 
- volume-model: estimating volume using 3D reconstruction methods
    - CODER OWNER: ADELE 
- weight-calculation: volume to weight estimations
    - CODER OWNER: MACKENZIE 

**Authors:** Mackenzie Snyder, Alexis Bader, Adele Younis, Gavin Depiero
